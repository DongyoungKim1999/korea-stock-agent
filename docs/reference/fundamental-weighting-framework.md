# 기본적분석 가중치 프레임

fundamental-analyst가 A8 단계(안정성/성장성/활동성 각 1~5점 산출)에서 따라야 하는 기준.
financial-ratio-analyzer의 출력(`relative_favorability` 등)을 이 프레임으로 점수화한다.

**점수는 카테고리마다 독립적인 1~5점 유리수** (소수 1자리 권장, 예: 3.4). 세 카테고리를 하나로
합산하지 않는다 — 안정성/성장성/활동성은 서로 다른 질문에 대한 답이라 합산하면 의미가 희석된다.

## 기본 공식

카테고리 내 지표들의 `relative_favorability`(financial-ratio-analyzer가 이미 "1보다 크면 유리"로
정규화해둔 값)를 **기하평균**으로 합친다 — 비율값은 산술평균이 아니라 기하평균으로 합치는 것이
통계적으로 맞다(2배 유리한 지표 하나와 0.5배 불리한 지표 하나가 있으면 산술평균은 1.25로 왜곡되지만
기하평균은 1.0으로 정확히 상쇄된다).

```
category_favorability = geometric_mean(relative_favorability_1, relative_favorability_2, ...)
  (null 값은 제외; 전부 null이면 해당 카테고리는 "산출불가"로 보고하고 점수를 매기지 않는다)

ratio_for_log = max(category_favorability, 0.05)   # 음수/0 방어 (예: 영업손실로 이자보상배율이 음수인 경우)

score = clamp(3 + sensitivity × 2.16 × ln(ratio_for_log), 1.0, 5.0)   # 소수 1자리로 반올림
```

`2.16`은 "산업평균 대비 정확히 2배 유리하면 +1.5점, 절반 수준이면 -1.5점" 정도가 되도록 잡은
확산계수다(ln(2)≈0.693, 0.693×2.16≈1.5). 산업평균과 동일(favorability=1.0)하면 `ln(1)=0` →
정확히 3.0점(중립)이 된다.

## sensitivity (업종별 가중치 조정)

기본값은 모든 카테고리 `sensitivity = 1.0`. 설계서 §2.2가 예시로 든 두 가지 조정만 적용한다
(그 외 임의 조정 금지 — 일관성을 위해 두 케이스로 제한):

| 업종 특성 | 조정 | 적용 카테고리 | sensitivity |
|---|---|---|---|
| 자본집약 업종 (예: 제조/장치산업/유틸리티) | 안정성 비중↑ | 안정성 | 1.3 |
| 성장산업 (예: 바이오/2차전지/신기술) | 성장성 비중↑ | 성장성 | 1.3 |
| 위 어느 쪽도 아니거나 판단 애매 | 조정 없음 | 전체 | 1.0 |

업종 특성 판단은 `induty_code`와 회사명·주요 제품을 근거로 LLM이 직접 판단하고, 리포트에
"자본집약적 업종 특성을 반영해 안정성 지표에 가중" 처럼 **판단 근거를 반드시 명시**한다. 두 조건에
모두 해당하는 업종(드묾)이면 두 카테고리 모두 1.3을 적용해도 된다.

## 활동성(activity) 지표의 주의사항

`asset_turnover` 등은 financial-ratio-analyzer 주석대로 분기 누적치 기준이라 연환산이 아니다.
따라서 절대 수치 자체보다 **산업평균 대비 상대값**(`relative_favorability`)만 신뢰해서 판단할 것 —
동일 분기·동일 누적기준으로 target과 peer를 같은 방식으로 계산했으므로 상대비교는 유효하다.

## 계산 예시 (fixture 데이터 기준)

안정성 지표 3개의 `relative_favorability`가 각각 1.807 / 1.079 / 1.083이면:
`geometric_mean = (1.807×1.079×1.083)^(1/3) ≈ 1.284`, `ln(1.284) ≈ 0.250`,
자본집약 업종이 아니라 가정(sensitivity=1.0)하면 `score = 3 + 1.0×2.16×0.250 ≈ 3.5점`.

성장성 지표 3개가 1.318 / 2.445 / 4.300이면 `geometric_mean ≈ 2.403`, `ln(2.403) ≈ 0.877`,
성장산업이라 sensitivity=1.3이면 `score = 3 + 1.3×2.16×0.877 ≈ 5.46` → **1~5 범위로 clamp해 5.0점**.
이렇게 극단값(5.0)이 나오면 report-formatter가 입력값과 무관하게 자동으로 "재검토 권장" 배너를
붙인다 — LLM이 별도로 플래그를 챙기지 않아도 된다(A9 확정 정책).

## 리포트 서술 요구사항

- 카테고리별로 사용한 지표, `comparison_basis`(industry_average/market_average_fallback/unavailable),
  sensitivity 조정 여부와 이유를 명시
- `comparison_basis: "unavailable"`이면 점수 자체를 매기지 말고 절대 수치만 서술 (비교 기준이
  없는데 점수를 매기면 근거 없는 숫자가 된다)
