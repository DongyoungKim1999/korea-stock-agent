# 밸류에이션·퀄리티·리스크 지표 참고자료

기존 기술적분석(가격신호)·기본적분석(업종 대비 안정성/성장성/활동성)에 더해, 실전 투자판단에
직접 쓰이는 세 축 — **얼마나 싼가(밸류에이션)·얼마나 좋은 회사인가(퀄리티)·얼마나 위험한가
(리스크)** — 를 추가로 산출한다. 전부 공신력 있는 검증된 방법론을 따르며, 무료 공개데이터
(개별종목 OHLCV + DART 재무제표)만으로 계산한다. 계산 위치는 기존 스킬 스크립트 안이라 웹
대시보드와 대화형 에이전트가 같은 값을 공유한다.

## 1. 퀄리티 — Piotroski F-Score & ROE/ROA

### Piotroski F-Score (0~9)
**출처**: Joseph D. Piotroski, "Value Investing: The Use of Historical Financial Statement
Information to Separate Winners from Losers", *Journal of Accounting Research* 38 (2000).
저PBR(가치주) 종목 중 F-Score 상위 그룹이 하위 그룹을 연 7.5%p 이상 아웃퍼폼함을 실증한,
학계·실무에서 널리 인용되는 대표적 퀄리티 스크리닝 지표다.

9개 항목을 각각 통과(1)/미달(0)로 채점한다:

| 구분 | 항목 | 판정 |
|---|---|---|
| 수익성 | ROA > 0 | 당기순이익 양수 |
| 수익성 | 영업활동현금흐름(CFO) > 0 | 현금흐름표 기준 |
| 수익성 | ROA 전년比 개선 | 당기 ROA > 전기 ROA |
| 수익성 | 이익의 질: CFO > 순이익 | 회계이익보다 현금이익이 큼(발생액 낮음) |
| 재무구조 | 레버리지 감소 | 부채/자산 전년比 하락 |
| 재무구조 | 유동비율 개선 | 유동자산/유동부채 전년比 상승 |
| 재무구조 | 신주발행 없음 | 자본금(액면) 전년比 불변 이하 |
| 효율성 | 매출총이익률 개선 | (매출-매출원가)/매출 전년比 상승 |
| 효율성 | 총자산회전율 개선 | 매출/자산 전년比 상승 |

**무료 데이터 제약에 따른 근사(방향성은 보존)**:
- 5번 레버리지: 정통 정의는 *장기부채/평균자산*이나, DART 계정만으로 안정적으로 뽑기 어려워
  *총부채/자산*으로 근사했다.
- 7번 신주발행: 발행주식수 시계열(KRX 차단) 대신 *자본금(액면)* 증감으로 근사했다.
- 계산에 필요한 값이 없는 항목(예: 금융업이라 매출원가 개념이 없음)은 채점에서 제외하고, 실제
  채점한 항목 수를 `max_score`로 함께 노출한다(예: 7/9가 아니라 7/8일 수 있음). 통과비율로
  해석하므로 분모가 달라도 일관된다.

전년 대비 비교는 DART가 각 계정에 함께 내려주는 전기(frmtrm) 값을 써서 **한 분기 보고서 안에서**
계산된다 — 추가 조회가 필요 없다.

### ROE / ROA
자기자본이익률(ROE = 순이익/자본총계)·총자산이익률(ROA = 순이익/자산총계). 워런 버핏이 가장
강조하는 자본효율 지표다. 분기보고서의 누계 순이익은 **연환산**(1분기 ×4, 반기 ×2, 3분기 ×4/3,
사업보고서 ×1)해서 연율 기준으로 표시한다(`annualized: true`로 표기).

## 2. 밸류에이션 — PER / PBR

가치투자의 기본. **좋은 회사라도 비싸게 사면 손실**이라는 원칙을 정량화한다.

- **PER(주가수익비율) = 주가 / 주당순이익(EPS, 연환산)** — 이익 대비 가격
- **PBR(주가순자산비율) = 주가 / 주당순자산(BPS)** — 순자산 대비 가격. **1배 미만은 시가총액이
  장부상 순자산보다 작다는 뜻**이라 그 자체로 의미 있는 저평가 신호로 표시한다.

### 발행주식수를 EPS로 역산하는 이유
KRX의 시가총액/상장주식수 엔드포인트는 클라우드/서버 IP를 차단해 GitHub Actions에서 쓸 수 없다.
그래서 **발행주식수 = 순이익 ÷ EPS** 로 역산한다(둘 다 DART가 내려주는 누계값이라 연환산 계수가
약분된다). 이렇게 얻은 주식수로 BPS(=자본총계/주식수)와 PER/PBR을 계산하므로, **종가 + DART
재무제표만으로** 밸류에이션이 나온다. EPS가 공시되지 않았거나 0이면 밸류에이션은 `unavailable`로
둔다(적자로 EPS가 음수면 PER은 "적자"로 표시).

**한계**: 시장 공표 PER/PBR과 소수점 오차가 있을 수 있다(연환산 방식·자기주식·우선주 처리 차이).
`basis: "eps_derived"`로 산출 기준을 명시하며, 정밀한 절대비교보다 **방향성(저평가/고평가 경향)과
동종업계·과거 대비 상대비교**의 참고용으로 쓴다. PER의 절대 고저 판단은 업종별 정상 배수가 크게
달라(성장주 vs 은행) 단정하지 않고 가벼운 방향 표시만 한다.

## 3. 리스크 — 변동성 / 최대낙폭 / 52주 위치

가격 시계열만으로 산출하는 리스크 관리 표준 지표(추가 조회 없음).

- **연율화 변동성** = 일간수익률 표준편차 × √252 × 100(%). 가격이 얼마나 출렁이는지. 국내
  개별주 대략 감각: 20% 미만 낮음 / 20~40 보통 / 40~60 높음 / 60%+ 매우 높음.
- **최대낙폭(MDD, Maximum Drawdown)** = 확보구간 내 고점 대비 최대 하락률. "물렸을 때 최악"을
  정량화 — 같은 기대수익이라도 MDD가 깊으면 심리적·자금관리상 버티기 어렵다.
- **52주 위치** = 현재가가 최근 1년(약 250거래일) 고저 밴드에서 차지하는 위치(0=연저점,
  100=연고점). 신고가 부근(추세 강함)인지 바닥권(낙폭과대/가치 재평가 여지)인지 한눈에 본다.

이 값들은 **점수(1~5)로 환산하지 않는다** — 방향성 판단이 아니라 "성격"을 보여주는 참고 수치이며,
해석은 대화형 에이전트(LLM)나 사용자의 몫이다(설계서의 스크립트=계산 / LLM=해석 분리 원칙).

## 종합 활용 관점

세 축은 서로 독립적이라 함께 봐야 입체적이다. 예:
- **저PBR + 高F-Score**: Piotroski가 실증한 전형적 우량가치주 후보(다만 저평가엔 이유가 있을 수
  있으니 성장성·업황과 교차확인).
- **高ROE·高성장 + 高PER + 高변동성**: 좋은 회사지만 이미 비싸고 흔들림이 큼 — 진입가·비중
  관리가 관건.
- **PBR<1 + 低F-Score + 바닥권**: 싸 보이지만 재무가 악화 중일 수 있는 '가치 함정' 경계 구간.

**면책**: 모든 수치는 과거 공시·시세에 기반한 참고 정보이며 투자자문·매매권유가 아니다. 백테스팅으로
검증된 매매전략이 아니라, 공신력 있는 지표들을 무료 데이터로 재현해 한 화면에 모은 것이다 — 최종
판단·책임은 사용자에게 있다.
