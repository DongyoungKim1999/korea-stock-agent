# 기술적분석 가중치 프레임

technical-analyst가 A4 단계(1~5점 산출)에서 반드시 따라야 하는 기준. technical-indicator-calculator의
출력(수치)을 이 프레임으로 해석해서 점수를 매긴다 — 임의의 가중치를 즉흥적으로 쓰지 않는다.

**점수는 1~5 유리수, 소수 1자리까지** (`automation/deterministic_scoring.py`의 자동화 파이프라인과
동일한 정밀도 — 여기서 정수로 반올림하면 같은 종목이 채팅 리포트와 대시보드에서 다른 값으로 보인다).
3점=중립, 4점 이상=매수, 2점 이하=매도(설계서 §1.2) 판정 자체는 정수 구간 기준 그대로 쓰되, 표시값은
소수 1자리를 유지한다.

## 카테고리 가중치

| 카테고리 | 가중치 | 구성 지표 |
|---|---|---|
| 추세계열 | 40% | 이동평균 정배열/역배열, 골든/데드크로스, MACD |
| 변동성/모멘텀 | 30% | RSI(14), 볼린저밴드 %B·밴드폭 |
| 거래량 | 20% | 20일 평균 대비 거래량 비율 |
| 캔들패턴 | 10% | 최근 1~3봉 패턴 |

우선순위(추세 > 모멘텀/변동성 > 거래량 > 캔들패턴)는 설계서에서 확정된 방향이며 변경하지 않는다.

## 산출 절차

1. 카테고리별로 **-2(강한 매도) ~ +2(강한 매수)** 사이의 서브점수를 아래 가이드로 판단
2. `가중합 = Σ(카테고리 서브점수 × 가중치)` → 범위는 자연히 -2~+2
3. `최종점수 = round(3 + 가중합, 1)` (소수 1자리 반올림, 정수 반올림 아님), 1~5 범위로 clamp
4. 근거 서술에 카테고리별 서브점수와 그 이유를 반드시 포함 (자기검증 시 "점수-근거 일치" 확인 대상)

## 카테고리별 판단 가이드

**추세계열** (`moving_averages`, `macd`)
- `alignment: "bullish"` (정배열) → +1.5 방향, `"bearish"`(역배열) → -1.5 방향
- 최근 골든크로스(`ma5_ma20_cross_recent.direction=="golden"`, 특히 5일 이내) → 가산, 데드크로스 → 감산
- MACD가 0선 위 + 히스토그램 확대 중 → 가산; 0선 아래 + 히스토그램 축소 중(하락 모멘텀 둔화) → 약한 가산으로 완화
- 단기(5·20일)와 장기(60·120일) 신호가 엇갈리면(`mixed`) 서브점수를 0 근처로 완화하고 근거에 "혼조" 명시

**변동성/모멘텀** (`rsi14`, `bollinger`)
- RSI: 30~70 중립 구간에서는 추세 방향에 동행시켜 판단(추세가 강세인데 RSI도 50~70이면 건강한 상승으로 가산). 70 이상은 과매수 경계(무조건 매도 아님 — 강한 상승추세 중 과매수는 감산 폭을 작게), 30 이하는 과매도 경계(반등 기대로 가산 가능하나 하락추세 중이면 감산 폭을 작게)
- 볼린저 `percent_b`: 1.0 초과(상단 이탈)는 추세 강도 신호로 가산 여지가 있으나 `bandwidth`가 이미 크게 확장된 상태에서의 상단 이탈은 과열일 수 있어 근거에 병기. 0 미만(하단 이탈)은 반대로 해석

**거래량** (`volume`)
- `ratio_to_avg20`이 1.5 이상이면서 가격이 상승 중이면 강한 가산(추세 신뢰도 확인), 가격 하락 중 거래량 급증이면 강한 감산
- `ratio_to_avg20`이 1.0 미만이면 가격 방향과 무관하게 서브점수를 0에 가깝게 완화
- **`abnormally_low: true`(20일 평균의 30% 미만)이면 추세계열·모멘텀 카테고리의 서브점수 절대값을 30% 축소**
  하고 근거에 "거래량 부족으로 가격신호 신뢰도 하향 조정" 명시 — 이것은 임의 조정이 아니라
  설계서 §2.2 참고박스에 명시된 규칙이다

**캔들패턴** (`candles.recent`)
- 최근 1~2봉의 패턴만 반영(오래된 봉은 이미 추세계열에 흡수됨). 장대양봉/상승장악형 → +1~+2, 장대음봉/하락장악형 → -1~-2, 도지 → 0(방향성 불확실), 나머지 특이패턴 없음 → 0
- 다른 카테고리와 방향이 반대면 가중치가 10%뿐이므로 전체 점수를 뒤집지 않도록 주의(과도한 영향 금지)

## 리포트 서술 요구사항

- 카테고리별 서브점수 4개를 모두 명시할 것
- 어떤 지표가 점수에 가장 크게 기여했는지 1~2문장으로 요약
- `technical-indicator-calculator`의 `warnings`(데이터 기간 부족 등)가 있으면 리포트에 그대로 노출
