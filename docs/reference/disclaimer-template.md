# Disclaimer 템플릿

report-formatter 스크립트가 모든 리포트 하단에 **그대로, 빠짐없이** 삽입하는 문구다 (설계서 C5).
이 파일이 유일한 원본이며, 문구를 바꾸려면 여기만 수정하면 된다 — 코드에는 하드코딩하지 않는다.

---

> **투자 유의사항**
>
> 이 리포트는 무료 공개 데이터(pykrx, DART Open API, 네이버 데이터랩/뉴스 API)를 기반으로 자동
> 생성된 **투자 참고 정보**이며, 투자자문이나 매매권유가 아닙니다. 시세는 최소 당일 종가 기준으로
> 장중 실시간 정보가 아니며, 재무데이터는 최근 공시된 분기 기준으로 현재 시점과 차이가 있을 수
> 있습니다. 점수와 서술은 AI가 규칙과 데이터를 바탕으로 산출한 것으로 오류나 편향이 있을 수
> 있습니다. **투자 판단과 그 결과에 대한 책임은 전적으로 투자자 본인에게 있습니다.**
